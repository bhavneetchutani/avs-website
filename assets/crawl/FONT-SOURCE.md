The Google Fonts response identifies this as the Latin subset, with ASCII coverage `U+0000-00FF`. The previous site asset is a Latin Extended subset and browser inspection showed ordinary English labels falling back to Menlo even after removing its CSS Unicode restriction. This asset supplies the missing Latin glyphs. It is used locally; no remote font request is needed when viewing the crawl.

The crawl stylesheet uses a relative font path:

```css
@font-face{font-family:'Spline Sans Mono';src:url('spline-sans-mono-latin-v13.woff2') format('woff2');font-weight:400 700;font-display:swap}
```
